# THE ZOOS 포트폴리오 데모

모든 내장 업무 데이터는 가상 예시입니다. 상품 58개와 연결된 재고·입고·주문·검토 데이터를 사용합니다.

- 상품/재고/입고: 23 → 58개
- 주문 분석: 10 → 58행, 매핑 예시: 5 → 24행
- 검토: 2 → 12건, 학습: 3 → 12건, 작업: 2 → 8건
- 마스터 이력: 1 → 4개, 입고 협의: 8 → 24건
- 도매 출고대기: 6 → 20건, 도매 출고완료: 2 → 8건
- 소매 출고: 6 → 20건, 대기 전표: 8 → 30건, 운영 입고 일정: 8 → 58건
- 전용 재고: 3 → 12건(화면에서 사용하는 필드 형식도 수정), 유통기한 로트: 0 → 15건

## 사용

정적 웹 서버 또는 Netlify에 index.html과 JS/CSS/assets를 올리면 됩니다. 실제 사이트에는 아직 배포하지 않았습니다. 같은 위치에서 실행해도 이전 운영 데이터·계정 설정을 읽지 않는 포트폴리오 전용 저장 키를 사용합니다. 날짜는 한국 기준 오늘을 중심으로 생성됩니다. 품절 화면은 카테고리를 선택하지 않으면 전체 품절 대상을 보여줍니다. ‘카테고리 초기화’는 분류와 의류 시즌 선택을 해제하며 검색어와 열 필터는 유지합니다.

관리자 시연 비밀번호: `PortfolioDemo!2026` (공개 데모용). 인증코드는 화면에 표시하며 실제 메일을 발송하지 않습니다. 기존 비밀번호와 개인 이메일, 업무용 구글시트 주소는 제거했습니다. 외부 시트 링크는 내장 데모 일정으로 대체했습니다. 외부 엑셀 라이브러리 CDN은 유지합니다.

상품·재고·입고의 공통 원본은 portfolio-data.js입니다. 브라우저 내 수정 및 업로드 기능은 유지되며, 직접 업로드한 데이터는 해당 브라우저에 저장됩니다. 공유 시 제공된 새 ZIP을 사용하세요. 상위 폴더의 기존 ZIP은 수정하지 않은 원본입니다.

## 검증

`node tests/portfolio-data.test.cjs`: 건수, 식별자 중복, 상품/주문 관계, 입고 일정, 창고 합계, 전용 재고, 소스의 업무 연결/개인 이메일/이전 저장 키 검사.

브라우저에서 전체 메뉴 및 운영 재고 화면 이동, 검토 수정 반영과 새로고침 후 저장, 협의 이력 중복 방지, 이전 저장 데이터 분리, 데모 관리자 비밀번호를 확인했습니다.
